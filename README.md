# Spam SMS Detection Using Machine Learning

## Project Overview
This project is designed to detect whether an SMS message is Spam or Ham (Not Spam) using Machine Learning and Natural Language Processing (NLP).

## Objective
The main objective is to classify SMS messages and identify unwanted spam messages automatically.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)

## Project Workflow
1. Load the SMS dataset.
2. Clean and preprocess text messages.
3. Convert text into numerical features.
4. Train the Machine Learning model.
5. Evaluate model performance.
6. Predict whether a message is Spam or Ham.

## Applications
- SMS spam filtering
- Message classification
- Detection of unwanted messages

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Upload or connect the required dataset.
3. Run all cells to train and test the model.
